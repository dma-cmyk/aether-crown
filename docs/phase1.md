# Phase 1 記録 (RTS最重要ループ)

## テスト結果 (Intel Iris Xe, Forward+, 描画あり)
- 50体 (25v25 + attack-move): 安定 66-70 FPS。交戦開始後は state が move→chase→atk へ遷移し、約20秒で決着。エラーなし
- 100体 (50v50 + attack-move): 移動中 40 FPS、激しい交戦中 31-33 FPS まで低下。ユニット数減少後は 66-68 FPS に回復。エラーなし
- ヘッドレス自動テスト `tests/skirmish_test.gd`: click選択=1、box選択=25、移動25/25、攻撃で目標HP 90→0 (死亡確認)。OK
- カメラ自動テスト `tests/camera_test.gd`: WASD前進・ホイールズーム OK。画面端スクロールと実機WASDは手動確認が必要

## 既知の問題 (Phase 2 以降で対応)
1. [解消] 戦闘終盤の交戦停止 → kill時ワイドスキャン (2.5x視界、イベント駆動) + 4秒毎の戦闘パルス (O(n)単一パス、bloodiedなIdleのみ attack-move) + 隊列スロットの障害物回避で解消。25v25・50v50とも殲滅を確認 (kills_p=25 / 50)。毎フレーム総当たりなし
2. [残] 100体激戦で31 FPS まで低下する場合あり (vsync時は60張り付きも確認)。内訳未計測。対策案: 物理補間・影距離短縮・分離の空間分割・HPバー/リングのマルチメッシュ化。現時点では大規模最適化しない
3. 25v25 が約20-30秒で決着する。バランス調整は Phase 2 (経済・生産が入ってから)
4. 敵AIはガード+リーシュのみ。追撃の打ち切り距離 34m。Squad AI は Phase 3 以降
5. カメラ実機プローブ (`tests/camera_probe.gd`, 描画あり): WASD/ストレイフ/ズーム/端スクロール/制限58.0/滑らかさ 全OK。起動ヒッチの大deltaは0.05sクランプで吸収 (最大1フレーム2m以下を構造保証)

## 操作

- HUDボタン: +25 vs 25 / 50 vs 50 / Reset
- CLI: `-- --units-per-side=N --auto-battle`
